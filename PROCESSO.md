# Processo do projeto

1. **Maquete.** O projeto reúne uma casa, um sobrado e uma garagem para demonstrar automação residencial.
2. **Programação.** O código do ESP32 lê os sensores e comanda dispositivos como luzes, ventilação e o servo do varal.
3. **Interface.** O projeto tem um painel web para monitorar e controlar as funções pela rede Wi-Fi.
4. **Apresentação.** A equipe preparou uma apresentação interativa com os conceitos, os componentes e a interface do ESP32.
5. **Portfólio.** A atividade reúne a versão em PDF, a apresentação interativa e os registros com legendas.
