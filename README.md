# Mundo SENAI 2026 — Casa inteligente

**Felipe Rezende Baroncelli**

## O que apresentamos

No Mundo SENAI 2026, nossa equipe apresentou uma maquete de casa inteligente para demonstrar sistemas embarcados e Internet das Coisas (IoT). O ESP32 lê os sensores, aplica as regras do programa e aciona dispositivos como luzes, ventilação e o motor do varal. O projeto também tem um painel web para acompanhar e controlar a maquete pela rede Wi-Fi.

## Para quem apresentamos

Apresentamos para alunos do 9º ano de escolas públicas, familiares e instrutores.

## Minha participação

Apresentei a maquete e expliquei o LED da casa, o varal automático e o sistema de ventilação.

## O que aprendi

Aprendi sobre sistemas embarcados e Internet das Coisas (IoT) e a trabalhar em equipe.

## Funcionamento do projeto

A maquete demonstra o uso do ESP32 para ler sensores, aplicar regras de automação e comandar iluminação, ventilação e o servo do varal. A interface web permite monitorar e controlar as funções pela rede Wi-Fi.

A apresentação interativa inclui um campo para abrir o painel do ESP32. Para usá-lo, conecte o computador ou celular à mesma rede do microcontrolador e informe o endereço configurado no equipamento.

## Tecnologias e execução

As páginas usam HTML, CSS e JavaScript e são publicadas pelo GitHub Pages. Para abrir os materiais localmente, baixe o repositório e abra o `index.html`, mantendo a pasta `fotos/` e os demais arquivos juntos.
